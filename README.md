# ASPHALTIKA Website

This is a lightweight static website for ASPHALTIKA. It uses plain HTML, CSS, and JavaScript so it can be hosted easily on GitHub Pages.

## Project Structure

- `index.html` is the home page.
- `about.html` explains the company background.
- `products.html` lists the main product range.
- `services.html` lists consultancy services.
- `contact.html` contains phone, WhatsApp, email, address, hours, and an enquiry form.
- `privacy-policy.html` contains a simple privacy policy.
- `css/style.css` controls the complete visual design.
- `js/script.js` controls the mobile menu and automatic footer year.
- `images/` stores website images and visual assets.
- `assets/` is ready for future files such as PDFs, brochures, or certificates.

## Preview Locally

Open `index.html` directly in a browser to preview the website. Because this is a static site, no backend server is required.

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload all project files and folders to the repository.
3. Go to the repository settings.
4. Open the Pages section.
5. Choose the main branch and the root folder.
6. Save the settings.

GitHub will publish the website and provide a live URL.
